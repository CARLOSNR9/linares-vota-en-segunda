# LinaresVotaEnSegunda

Aplicación web moderna, responsive y optimizada para dispositivos móviles diseñada para visualizar de forma interactiva los resultados de la Segunda Vuelta Presidencial 2026 en el municipio de Linares, Nariño.

## Tecnologías Utilizadas

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **React Router v7**
- **Chart.js** y **react-chartjs-2** (Para visualización de datos)
- **Lucide React** (Para íconos)
- Datos estáticos en formato **JSON** (Sin backend)

## Requisitos Previos

- Node.js (versión 18 o superior recomendada)
- npm o yarn

## Instalación y Configuración

1. Clonar este repositorio.
2. Instalar las dependencias del proyecto:

   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:

   ```bash
   npm run dev
   ```

4. Abrir en el navegador (usualmente `http://localhost:5173`).

## Construcción para Producción

Para compilar el proyecto y prepararlo para despliegue (en GitHub Pages, Vercel, o similar):

```bash
npm run build
```

El resultado se generará en la carpeta `dist`.
